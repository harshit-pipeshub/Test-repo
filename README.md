# Test-repo — Sample files

This repository has a small set of example files added to demonstrate a few different file types and how to run them.

Files added in this commit:

- README.md — this file
- src/main.py — simple Python entrypoint
- src/utils.py — small utility function used by main.py
- web/index.html — minimal web page
- web/script.js — small JavaScript used by the web page

How to run the Python example:

1. From the repository root run:

   ```bash
   python3 src/main.py
   ```

How to open the web example:

1. Open web/index.html in a browser (double-click or serve with a static server).

Feel free to edit or remove any of these sample files.
